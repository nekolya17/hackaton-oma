# 🚚 ОМА ПО ПУТИ (OMA On-The-Way)
> **Экосистема попутного бытового сервиса (ОМА + ОМА КСТАТИ + ОМА PRO)**  
> Прототип B2B2C платформы для хакатона.

---

## 💡 О проекте
**«ОМА ПО ПУТИ»** — геопространственный сервис, который соединяет 4 000+ верифицированных строителей и мастеров из программы **ОМА PRO** с повседневными бытовыми заказами жителей Минска (установка смесителей, монтаж люстр, подключение бойлеров) по пути с работы домой.

Сервис позволяет отдельно вызвать мастера или добавить установку к товару в корзине. Клиент создаёт заявку, а карточку специалиста получает после того, как мастер примет заказ.

---

## 🌟 Ключевые модули прототипа

### 1. 🛒 Глазами Покупателя (B2C Smart Checkout)
- Интерактивный каталог (смесители, люстры, водонагреватели, унитазы).
- В шапке есть отдельный раздел «Вызов мастера»: клиент выбирает работу из списка или описывает задачу своими словами.
- В корзине покупатель отмечает товары для установки. Время приезда мастера следует за выбранным окном доставки.
- Все товары корзины входят в покупку; отметки на карточках определяют только товары для установки мастером.
- Чтобы показать фото товара в вертикальной корзине, положите изображение в `public/products/` и добавьте к товару в `src/data/mockData.ts` поле `imageUrl: '/products/имя-файла.jpg'`. Если фото не указано, отображается иконка категории.
- Киллер-виджет **«Установить с ОМА ПО ПУТИ»**:
  - Честная экономия **42%** (35 BYN против 60 BYN на открытом рынке).
  - Карточка мастера появляется у клиента после принятия заявки.
  - Списание баллов программы лояльности ОМА.
  - Анимированное подтверждение с конфетти и мгновенная реактивная отправка заявки в диспетчерскую.

### 2. 🗺️ Гео-Диспетчер H3 (Live Карта Минска)
- Интерактивная карта на базе Leaflet с живой сеткой районов (*Новая Боровая, Минск-Мир, Уручье, Лебяжий*).
- Слой гипермаркетов ОМА и магазинов **«ОМА КСТАТИ»** с пульсирующими зонами покрытия.
- Слой мастеров ОМА PRO и заказов в реальном времени.
- Визуализация гексагональных зон плотности спроса (**H3 Hexagons**).
- **Попутный алгоритм матчинга**: построение коридора отклонения (*всего +400 м / +7 мин от основного маршрута*).

### 3. 👷 Кабинет Мастера (ОМА PRO)
- Профиль мастера (рейтинг 4.92, верификация, статистика).
- Карта попутных заказов с деталями работы и доходом за каждый заказ.
  - Жизненный цикл заказа: *Выбрать на карте ➔ Принять ➔ Выполнить*.

### 4. 📊 Юнит-экономика и CJM для жюри
- Интерактивные слайдеры бизнес-модели (объем заказов, средний чек, комиссия платформы, допродажи товаров).
- Финансовый прогноз (GMV, маржинальный доход, CAC = 0 BYN).
- Инфографика Customer Journey Map (CJM) для всех 3 стейкхолдеров.

## 🛠 Стек технологий
- **Фронтенд:** React 19, TypeScript, Vite
- **Стилизация:** Tailwind CSS, Lucide React Icons
- **Картография:** Leaflet, React-Leaflet
- **Анимации и эффекты:** Canvas-Confetti, CSS Keyframe Animations
- **Бэкенд (первый этап):** Python, FastAPI, SQLite; серверный расчёт стоимости и сохранение заказов
- **Текущее соединение:** React пока использует локальный Shared State Context; API запускается отдельно

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте [http://localhost:5173/](http://localhost:5173/) в браузере.

На стартовом экране выберите роль «Покупатель» или «Мастер». Покупателю доступны корзина и вызов мастера, а мастеру — только его кабинет. Роль можно сменить кнопкой в шапке.

Карта Минска использует тайлы OpenStreetMap и не требует API-ключа. Если после обновления кода в браузере всё ещё видна надпись «API KEY REQUIRED», остановите сервер сочетанием `Ctrl+C`, снова выполните `npm run dev` и обновите страницу.

Для другого XYZ-провайдера скопируйте `.env.example` в `.env.local` и заполните URL тайлов, атрибуцию и, если требуется, браузерный API-ключ. Файл `.env.local` не добавляется в Git; переменные `VITE_` всё равно доступны в браузере, поэтому ключ должен быть ограничен по домену в настройках провайдера.

### 3. Продакшн-сборка
```bash
npm run build
```
Сборка сохраняется в директорию `dist/`.

### 4. Запуск API

Из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
python -m uvicorn backend.app:app --reload --port 8000
```

Документация API: [http://localhost:8000/docs](http://localhost:8000/docs). Заказы хранятся в `backend/data/orders.sqlite3` (файл не добавляется в Git). Для другого пути к базе задайте переменную `OMA_DB_PATH`.

Доступны `GET /api/v1/health`, `GET /api/v1/products`, `GET /api/v1/slots`, `POST /api/v1/quotes`, `POST /api/v1/orders`, `GET /api/v1/orders` и `GET /api/v1/orders/{id}`. В `POST /api/v1/quotes` передаются `product_ids` для всей покупки, `installation_product_ids` для работ мастера, `slot_id` и `use_bonus`. Сервер проверяет выбор и сам рассчитывает цену.

Проверка API:

```bash
pip install -r backend/requirements-dev.txt
pytest backend/tests
```

5. Подключить реальный геопоиск и маршрутизацию, затем развернуть API и фронтенд с мониторингом.
